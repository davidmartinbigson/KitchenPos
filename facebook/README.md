## 5. Page banane ka tareeqa (5 minute) — step by step

1. Apne Facebook account mein jao → Menu (☰) → **Pages** → **Create new Page**
2. **Name**: `Kitchen POS` · **Category**: `Software` likho aur select karo · **Bio**: upar wala English bio paste karo → **Create**
3. **Profile photo** upload: is folder ka `logo.png`
4. **Cover photo** upload: is folder ka `cover.png`
5. Page kholo → **Add action button** → **Sign Up** → link: `https://prokitchenpos.com/signup`
6. Settings → **Username** set karo (upar wali list se jo mile)
7. About/Website ka section bharo (upar ka long description)
8. **Post 1** paste karo + cover.png laga do → publish → phir us post ko **Pin to top** karo
9. Apne doston/page likes ke liye **Invite friends** dabao
10. WhatsApp status + apne restaurant customers ke groups mein page link share karo 🎉
